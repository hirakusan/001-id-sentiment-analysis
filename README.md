Real-time sentiment analysis untuk platform social media Indonesia dengan fokus pada Bahasa Indonesia dan bahasa gaul/slang detection.

## 🎯 Features

- ✅ Multi-platform data collection (Twitter, Instagram, YouTube)
- ✅ Indonesian language preprocessing dengan slang normalization
- ✅ Real-time sentiment monitoring dashboard
- ✅ Emotion detection (joy, anger, fear, sadness, surprise)
- ✅ Trend analysis dan visualizations
- ✅ REST API untuk integration
- ✅ Dockerized deployment

## 🚀 Quick Start

```bash
git clone https://github.com/hirakusan/id-sentiment-analysis
cd indonesian-sentiment-analysis
pip install -r requirements.txt
streamlit run streamlit_app/app.py
